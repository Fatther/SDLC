# Глоссарий проекта PriceRadar

Версия 0.1 · 2026-11-09 · Аникевич Павел Петрович

Глоссарий составлен по SRS 0.2 (`docs/srs/srs.md`) и SDD (`docs/sdd/sdd.md`). Термины разделены на три группы. Если термин определён в SRS или SDD, значение здесь совпадает с определением там.

## 1. Предметная область

| Термин | Определение | Источник |
|--------|-------------|----------|
| Адаптер магазина | Модуль, который извлекает данные о товаре со страниц конкретного магазина и реализует интерфейс `PriceSource` | SRS 1.3 |
| Администратор | Владелец продукта; ведёт календарь распродаж и включает или отключает адаптеры | SRS 2.4 |
| Алерт | Уведомление пользователя о событии по товару: достигнута целевая цена, цена снизилась, товар появился в наличии | SRS 1.3 |
| Архивный товар | Товар, который сохранён в списке, но не проверяется и не создаёт алертов | REQ-FUNC-006 |
| Вишлист | Список товаров, за ценой которых пользователь следит | SRS 1.3 |
| Гость | Посетитель без учётной записи; может зарегистрироваться или открыть публичную ссылку | SDD 006 |
| Календарь распродаж | Набор событий («Чёрная пятница», 11.11, Новый год, 8 Марта), по которым строится окно покупки | REQ-FUNC-020 |
| Лента скидок | Раздел «Скидки»: товары пользователя, подешевевшие не менее чем на 5 % за 30 дней | REQ-FUNC-017 |
| Медиана цены | Серединное значение цены за период; устойчиво к разовым выбросам | SRS 1.3 |
| План покупок | Набор товаров с рекомендацией «Купить сейчас», выбранный под месячный бюджет, и остаток бюджета | REQ-FUNC-022 |
| Покупатель | Зарегистрированный пользователь, ведущий вишлист | SRS 2.4 |
| Приоритет | Важность товара для пользователя: высокий, средний, низкий | REQ-FUNC-005 |
| Публичная ссылка | URL со случайным токеном, открывающий список только для чтения без входа | SDD 1.3 |
| Рекомендация | Один из четырёх выводов: «Купить сейчас», «Подождать», «Нейтрально», «Недостаточно данных» — с числовым обоснованием | REQ-FUNC-019 |
| Список | Именованная группа товаров («Ноутбук», «Подарки»); не более 20 на пользователя | REQ-FUNC-007 |
| Фиктивная скидка | Снижение цены до обычного уровня после предварительного искусственного повышения | SRS 1.3 |
| Целевая цена | Цена, при достижении которой пользователь хочет получить алерт | SRS 1.3 |
| Ошибка проверки | Статус товара после трёх подряд неудачных проверок | REQ-FUNC-011 |

## 2. Термины модели UML

| Термин | Определение |
|--------|-------------|
| Актёр | Роль, которую по отношению к системе играет пользователь, внешняя система или время |
| Альтернативный поток | Ветвь потока событий, выполняемая при особом условии или ошибке |
| Include (включение) | Связь прецедентов: базовый прецедент всегда выполняет включаемый как часть себя |
| Extend (расширение) | Связь прецедентов: расширяющий прецедент выполняется только при условии в точке расширения базового |
| Линия жизни | Вертикальная линия участника на диаграмме последовательности |
| Основной поток | Типичный успешный сценарий прецедента |
| Постусловие | Состояние системы, которое гарантируется после завершения прецедента |
| Предусловие | Условие, которое должно выполняться до запуска прецедента |
| Прецедент | Последовательность действий системы, дающая актёру значимый результат |
| Составное состояние | Состояние, внутри которого определены вложенные состояния |
| Сторожевое условие | Булево выражение в квадратных скобках на переходе; переход срабатывает при его истинности |
| Точка расширения | Место в базовом прецеденте, где может подключиться расширяющий |
| Дорожка (swimlane) | Область диаграммы активности, соответствующая участнику или модулю |

## 3. Технические термины

| Термин | Определение |
|--------|-------------|
| ADR | Протокол архитектурного решения |
| ArchUnit | Библиотека проверки допустимых зависимостей модулей тестами |
| JSON-LD | Формат микроразметки schema.org, в котором магазины публикуют цену товара |
| Outbox | Таблица исходящих сообщений, записываемых в одной транзакции с бизнес-данными и доставляемых отдельным обработчиком |
| PlantUML | Язык текстового описания диаграмм UML |
| Price API | Внутренний REST-интерфейс получения нормализованных цен по URL товара |
| PriceSource | Java-интерфейс адаптера магазина |
| robots.txt | Файл правил для автоматических клиентов на сайте магазина (RFC 9309) |
| SKIP LOCKED | Режим блокировки строк PostgreSQL, пропускающий уже захваченные строки |
| SSRF | Атака, при которой сервер вынуждают обратиться по подставленному адресу |
| Токен ссылки | Случайное значение в публичном URL; в БД хранится только его SHA-256 |
| Кэш Price API | Хранилище ответов на 5 минут, до 10 000 записей |
