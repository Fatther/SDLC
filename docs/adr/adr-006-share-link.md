# ADR-006: Непрозрачный случайный токен публичной ссылки

## Контекст и постановка задачи

Во втором раунде Заказчик попросил делиться списком (например, «Подарки») по ссылке только для просмотра (REQ-FUNC-025/026). Гость не авторизован, поэтому ссылка — единственная защита. Как построить ссылку, чтобы её нельзя было угадать, можно было мгновенно отозвать и она не раскрывала приватные данные?

## Драйверы решения

* Неугадываемость: не менее 128 бит из криптостойкого генератора (REQ-SEC-007).
* Мгновенный отзыв и пересоздание.
* Минимальный объём данных в ответе (REQ-FUNC-026).
* Срок: функция должна уместиться в 24 ч оценки (F-15).

## Рассмотренные варианты

* Случайный токен с хэшем SHA-256 в БД
* Подписанный токен (JWT) без хранения
* Числовой идентификатор списка

## Итог решения

Выбранный вариант: «Случайный токен с хэшем SHA-256 в БД», потому что ссылку можно отозвать удалением записи, а токен невозможно восстановить из базы. Токен — 32 случайных байта в base64url; ответ формируется из белого списка полей (название списка, название, изображение, цена, магазин, ссылка на товар).

### Последствия

* Хорошо, потому что отзыв действует немедленно.
* Хорошо, потому что утечка БД не раскрывает рабочие ссылки.
* Плохо, потому что потерянную ссылку нельзя показать повторно, её нужно пересоздать.
* Плохо, потому что каждый просмотр требует обращения к БД; добавляется лимит 60 запросов в минуту с IP.

### Подтверждение

Автотест проверяет: в БД нет токенов в открытом виде; отозванная и неверная ссылки возвращают одинаковый 404; ответ не содержит запрещённых полей; 61-й запрос за минуту возвращает 429.

## Плюсы и минусы вариантов

### Случайный токен с хэшем SHA-256 в БД

* Хорошо, потому что отзыв и аудит просты.
* Плохо, потому что нужна таблица и обращение к БД.

### Подписанный токен (JWT) без хранения

* Хорошо, потому что без хранилища.
* Плохо, потому что отзыв до истечения срока требует чёрного списка.

### Числовой идентификатор списка

* Хорошо, потому что проще всего.
* Плохо, потому что идентификаторы перебираются и чужие списки раскрываются.
